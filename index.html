📖 Tutorial

  1. Login: Enter name + password. Upload a badge photo — it persists permanently. Double-click your ID card at any time to instantly log out.
  2. API Key: Paste your Anthropic API key in the banner at the top. All AI features (question generation, response analysis, insights) use it.
  3. Start a Case: Describe the case and click Start New Investigation. A Case ID is auto-generated and scores update.
  4. Subjects Database: Add suspects or witnesses with full profile details. View, filter, or delete entries from the database modal.
  5. Interrogation: Select a subject type and name. Use AI Generate Question for smart follow-up questions. Capture unlimited photo/video/audio evidence.
  6. Analyze Responses: Type or transcribe the subject's answer, then click AI Analyze Response for a truth score and follow-up suggestions.
  7. Crime Board: Drag any photo, video, or audio onto the board. Click an item to select it (glows blue). Enable Connect Mode and click two items to draw a colored line between them. Change the line color with the color picker.
  8. Evidence Photos: Upload crime scene and evidence photos, then add them to the board.
  9. AI Insights: Click Generate AI Insights for a full case analysis with guilt probability meters.
  10. Solve Case: Click SOLVE CASE to close the investigation and update your score.
  11. Save/Load: Use Save Case File to download your case as JSON, and Load Case File to restore it.
